Sociogram

Visual representation of the similarity between users, based on their item ratings. It uses a force-based layout, meaning similar nodes are pulled to each other while dissimilar nodes are pushed away from each other. The similarities are normalized to a value between 0.0 and 1.0. The similarity threshold determines whether an edge between two nodes is drawn.
