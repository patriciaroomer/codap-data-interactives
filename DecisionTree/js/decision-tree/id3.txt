Algorithm

1. Start with all training data
2. Calculate entropy of current subset
3. For every available attribute:
     a. Split data by attribute values
     b. Calculate weighted entropy
     c. Calculate information gain
4. Select attribute with highest information gain
5. Create a decision node
6. Create one branch per attribute value
7. For each branch:
     a. If pure → create leaf
     b. If no attributes left → majority-class leaf
     c. Otherwise recurse
8. Repeat until every branch ends in a leaf


User Interface

1. create training data
    a. add attributes: text box, 'add attribute' button, 'apply' button
    b. add target classes: text box, 'add class' button, 'apply' button
    b. input form, yes/no drop-downs per attribute, target class drop-down, 'add' button, 'apply' button

2. training process
    a. 'train' button
    c. decision tree rendering 

3. testing process
    a. input form, yes/no drop-downs, 'apply' button  
    b. decision tree prediction
